# Nutzung

Die Konfiguration erfolgt über das **Site Set** und die **Site Settings**. Plugin-Instanzen können Storage-Ordner und Zielseiten im FlexForm überschreiben.

Anschriften gehören immer zu einem **Standort**. Organisationen haben keine Straßenfelder.
