# Installationsanleitung

Diese Anleitung hilft bei Installation und Einrichtung von Directory.

## Schnellstart

1. Extension per Composer installieren
2. Site Set aktivieren
3. Storage-Ordner sowie Listen- und Detailseiten in den Site Settings setzen
4. Datensätze anlegen und Plugins auf Seiten platzieren

## Voraussetzungen

- TYPO3 13.4+ / 14.0+
- PHP 8.2+
